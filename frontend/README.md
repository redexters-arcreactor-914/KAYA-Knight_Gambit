# NETRA — Frontend

React frontend for the Network Intelligence & Threat Relationship Analysis system.

## Local setup

Make sure the backend is running first (see `../backend/README.md`,
should be live on `http://localhost:8000`).

```bash
cd frontend
npm install
npm run dev
```

Open `http://localhost:5173`. Log in with one of the officer accounts from
the backend seed script (e.g. `supervisor` / `supervisor123`).
